Globe Trotter: Personalized Travel Planning
🎯 Project Overview & Problem Statement
Globe Trotter is an end-to-end travel planning application designed to simplify complex, multi-city journeys. Based on the requirements in the "GlobeTrotter.pdf" document, the core problem statement challenges developers to build a responsive, user-centric platform that empowers travelers to organize customized trips, stay within budget, and gain full visibility of their itineraries. The ultimate vision is to make travel planning as collaborative and exciting as the trip itself. 

Core Capabilities
To solve the complexities of modern travel planning, the application must include several essential functionalities:
- User Workspace: A centralized dashboard and trip-list screen to authenticate users and manage all upcoming or past personalized travel plans.
- Smart Itinerary Builder: An interactive interface where users can search for destinations, add multi-city stops, and assign specific experiences to travel dates. 
- Budget Management: A summarized financial screen providing estimated total costs, daily averages, category breakdowns (transport, meals, stays), and alerts for over-budget days.  
- Visual Timelines: Calendar and timeline views allowing users to visualize their day-by-day plan and effortlessly drag-to-reorder activities.  
- Social Sharing: A public itinerary view feature enabling users to generate sharable URLs for others to view, draw inspiration from, or copy their trips.  
🛠️ Technical Focus
Successfully developing Globe Trotter requires strong full-stack execution. The backend must utilize a well-designed relational database to efficiently store, retrieve, and map complex travel data like user profiles, multi-city stops, and estimated expenses. The frontend must deliver a smooth, dynamic user interface that adapts intuitively to each user's unique trip-planning flow across desktop or mobile platforms
